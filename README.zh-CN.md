# AlonaBot 色图插件

[English](README.md)

在聊天里发「来份色图」，插件会回复一张随机的非 R18 原图。用「来1份色图」「来二份色图」或「来三份色图」指定数量，支持 1–10 张，也可以用「两」。由 `/setu` 升级时，请改用上述短语。

## 设置单次发送上限

`max_pictures` 默认是 `10`，可设为 1–10 的整数。例如设为 `3` 后，「来三份色图」照常发图；「来四份色图」会提示上限，且不请求图源。这个设置适用于所有适配器和发送方式。

## 配置 OneBot 11 的发送形式

在 AlonaBot 的插件配置中修改 `forward_mode`：

| 值 | OneBot 11 的发送方式 |
| --- | --- |
| `off`（默认） | 一条图片消息链 |
| `multi` | 单图直发，多图合并转发 |
| `always` | 单图、多图都合并转发 |

其他适配器始终收到一条图片消息链。插件验证原图后才发送，失效图片只补缺额，最多补两轮。上游返回 5xx 时直接结束；无法发图时回复一条中文提示。

## 本地验证与打包

使用与本仓 `go.mod` 匹配的 SDK 与 CLI，运行 `alonabot run .` 后在控制台输入「来份色图」。该命令访问真实图源；离线验证见[开发指南](docs/development.md)。

Linux amd64 打包：`alonabot pack . --target linux/amd64`。维护者发布步骤见[贡献指南](CONTRIBUTING.zh-CN.md#打包与发布)。
